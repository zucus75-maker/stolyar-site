Что входит в проект

Каждый готовый проект — это комплект документации, достаточный для изготовления изделия без догадок и пересчётов «на глаз». В комплект входят:

  • PDF-чертежи высокого качества — общие виды, узлы, разрезы, схема сборки. Формат А3/А4, готов к печати.
  • DXF-файлы для ЧПУ — контуры деталей для станка. Без возможности редактирования, только для производства.
  • Спецификация материалов — перечень досок, крепежа, фурнитуры с размерами и количеством.
  • Пошаговая инструкция — порядок сборки с пояснениями по узлам.

Для кого

Для частных застройщиков, которые собирают беседку или лестницу своими руками; для столярных мастерских, которым нужен готовый раскрой; для дизайнеров интерьера, которым важно показать клиенту точный проект.

Что можно сделать с чертежом

Строить по нему без переделок, отдать в цех для раскроя, адаптировать под свои размеры (услуга «Индивидуальный проект»), использовать как основу для собственных доработок. Перепродажа и публикация файлов запрещены — это указано в оферте.

Оплата и получение

Можно ли изменить размеры готового чертежа? +
Да, мы можем адаптировать проект под ваши габариты. Стоимость услуги рассчитывается индивидуально после уточнения деталей.
Что я получу после оплаты? +
Вы получите письмо со ссылками: 1. Чертежи в формате PDF (высокое качество для печати). 2. Файлы для ЧПУ (только для станка, без редактирования). 3. Подробная спецификация материалов.
Как происходит оплата? +
Вы оставляете заявку на сайте. Мы связываемся с вами, высылаем ссылку на оплату (СБП, карта, счёт для юрлиц). После оплаты файлы приходят на вашу почту.
А если я не разберусь в чертеже? +
К каждому проекту прилагается пошаговая инструкция. Если возникнут вопросы — напишите нам в мессенджер, мы объясним.
Можно ли вернуть цифровой товар? +
Цифровой товар надлежащего качества возврату не подлежит после предоставления доступа к скачиванию. Если файл повреждён или не открывается — повторно предоставим доступ или вернём средства. Подробнее — в оферте.
